# Healing Slices 🍉🔪

Unity 2022.3.45f1 Android project.

## 수정 사항
- 칼 애니메이션은 짧은 고정 시간 안에 내려갔다 올라오며, 절단 입력은 한 번만 처리하도록 했습니다.
- 절단된 조각은 실제 절단면을 가진 별도 메시와 조각 크기의 콜라이더를 사용합니다. 다음 절단은 새로 만들어진 조각에 적용됩니다.
- 원본 과일에서 최대 3단계까지 절단할 수 있어, 반복 터치로 조각 수가 무한히 증가하지 않습니다.
- 파편과 과즙 이펙트 수를 줄이고 조각의 수명을 관리해 반복 절단 중 프레임 정지를 줄였습니다.
- 과일 생성 간격 조절 UI와 저장 설정을 제거하고, 약 1.5초(1.35~1.65초 랜덤) 간격으로 복구했습니다.
- PERFECT SLICES 카운터는 유지됩니다.

## Unity에서 열기
Unity Hub에서 이 폴더를 프로젝트로 추가하고 Unity 2022.3.45f1로 엽니다. `Tools > Create Main Scene` 메뉴로 씬을 만든 뒤 Play를 누릅니다. Android APK는 GitHub Actions workflow를 사용할 수 있습니다.

참고: 이 환경에서는 Unity Editor를 실행해 실제 기기/플레이 테스트를 수행하지 못했습니다. 빌드 후 절단면, 충돌, UI 배치를 확인해 주세요.
