# Healing Slices 🍉🔪

Unity 2022.3.45f1 Android project.

## 변경 사항
- 같은 과일에서 나온 조각도 다시 타격해 여러 단면으로 자를 수 있습니다.
- 과일 메시를 종류별로 변형해 사과·감귤류·레몬·수박·키위·복숭아·자두·용과 실루엣을 구분하고, 꼭지·잎·줄무늬·돌기를 추가했습니다.
- 우측 상단 `Less often` / `More often` 버튼 또는 `Spawn interval` 슬라이더로 생성 간격을 0.15~3.00초로 조절할 수 있습니다. 설정은 PlayerPrefs에 저장됩니다.

## Unity에서 열기
Unity Hub에서 이 폴더를 프로젝트로 추가하고 Unity 2022.3.45f1로 엽니다. `Tools > Create Main Scene` 메뉴로 씬을 만든 뒤 Play를 누릅니다. Android APK는 GitHub Actions workflow를 사용할 수 있습니다.
